SHIFTNAKE Android プライバシーポリシー

施行日：2026年11月19日（公開日から適用）・旧版：2026年11月17日施行版

  • アプリ：SHIFTNAKE Android（com.sleeplesshan.shiftnake）
  • 適用対象：現在の Google Play ビルド（製品版リリースおよびテストトラック）、バージョン名 1.0.0、バージョンコード 94、ランタイム v175
  • 運営者：Hanmin Kim（大韓民国の個人開発者）
  • プライバシーに関するお問い合わせ：hankim+shiftnake@mail.grokbot.com

本書は韓国語版・英語版と同じ内容の日本語版です。

1. 適用範囲

本ポリシーは、Hanmin Kim が提供する上記 SHIFTNAKE Android ビルドにおける端末内のゲームデータ、任意の Google Play ゲームズ ランキング、広告と同意、サポートへのお問い合わせに関する情報の取り扱いを説明するものです。アプリ内での年齢確認はありません。アプリは年齢を尋ねたり、読み取ったり、保存したりしません。子ども向け取り扱いのフラグ（TFCD）、同意年齢未満のフラグ（TFUA）、年齢制限付きの取り扱いは設定せず、パーソナライズされていない広告のみに限定することもしません。広告コンテンツのレーティング上限は T です。SHIFTNAKE は13歳未満の子どもを対象としておらず、Google Play での対象年齢は13歳以上です。

サポートサイトへのアクセスとサポートメールの取り扱いについては、別途ウェブサイト・お問い合わせに関するプライバシー案内で説明しています。本書は Android アプリに関するもので、ウェブサイトの案内とは別のものです。

2. 端末内のゲームデータ

ゲームの提供と進行状況の保持のため、次の情報をアプリ専用の端末内データベースに保存します。

  • 進行状況とウォレット（所持フルーツなど）
  • 実績
  • ベストスコア
  • 選択中のスキン、ゲームモード、難易度
  • サウンド・音楽のオン／オフ、音量、言語、片手モード、グラフィック品質
  • 広告表示の記録：ゲームオーバーの回数、インタースティシャル広告の表示予定の有無、リワード広告後の60秒のクールダウン
  • 端末内にのみ保存される1日1回の報酬の記録：デイリーフルーツの日付（shiftnake-daily-fruit-date-v1）、デイリーシールドの日付（shiftnake-daily-shield-date-v1）、デイリーマグネットの日付・回数・待機フラグ（shiftnake-daily-magnet-v1）
  • オンボーディングの完了
  • テスター向け 50,000 フルーツ付与の1回限りのローカル受領記録

最後に再生した音楽トラックの ID はそのセッション中のみ保持され、このデータベースには含まれません。音楽と効果音のファイルはアプリに含まれており、アップロードされません。

開発者が運営するアカウント、ログイン、リモート保存サーバーはなく、アプリのコードがこれらのデータをアップロードすることはありません。分析 SDK やクラッシュ報告 SDK もありません。Google SDK の通信、UMP SDK が保存する同意状態、OS のバックアップは、このデータベースとは別のものです。

Android のバックアップは許可されています。端末、OS の設定、バックアップサービスによっては、アプリのデータが Android のバックアップや端末間の移行でコピーされる場合があります。これは開発者が運営するアカウント型のクラウド保存ではありません。旧ファイル shiftnake_age_band はこのバックアップと移行の対象外です。アプリはこのファイルを読み書きしません。

3. 直接入力を求めない情報

アプリは会員登録や、氏名、電話番号、公的な識別番号、生年月日、年齢の入力を求めません。カメラ、マイク、位置情報、連絡先へのアクセスも求めません。

アプリ内での年齢確認はありません。アプリのどの部分も年齢を読み書きしません。

アプリが宣言している権限は INTERNET、ACCESS_NETWORK_STATE、com.google.android.gms.permission.AD_ID です。ライブラリにより WAKE_LOCK、FOREGROUND_SERVICE、DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION が追加されます。本ビルドには ACCESS_ADSERVICES_AD_ID、ACCESS_ADSERVICES_ATTRIBUTION、ACCESS_ADSERVICES_TOPICS は含まれていません。

通常のオンライン状態の確認では、インターネット接続、検証済み、キャプティブポータルの各フラグを含む Android のネットワーク接続状態を読み取ります。アプリが独自の HTTP 接続確認を送信したり、接続履歴を開発者のサーバーにアップロードしたりすることはありません。OS や外部 SDK の通信はこれとは別です。

4. Google の広告・同意 SDK と通信

本ビルドには Google Mobile Ads SDK（play-services-ads）25.5.0、User Messaging Platform（UMP）4.0.0、Play Games Services（play-services-games-v2）22.1.0 が含まれています。メディエーション SDK、Firebase Analytics、Crashlytics、その他の分析 SDK やクラッシュ報告 SDK は含まれていません。Ads SDK に同梱される Google の測定ライブラリは含まれており、アプリ測定の初期化は Ads SDK の初期化まで遅らせています。Google Mobile Ads SDK は、AD_ID 権限と端末の設定に応じて Android の広告 ID を使用することがあります。広告 ID は Android の設定でリセットまたは削除できます。広告のリクエストと表示の過程で、Google は広告 ID やその他の端末・アプリの識別子、IP アドレス（おおよその位置の推定に使われることがあります）、端末・アプリの情報、広告への操作やその他のアプリ内アクティビティ、SDK の診断・パフォーマンス情報などを収集または受け取ることがあります。この SDK が処理しうる項目については、本書末尾にある Google のデータ開示情報をご覧ください。あわせてGoogle のサービスを使用するサイトやアプリから収集した情報の Google による使用とGoogle AdMobもご確認ください。

本ビルドは運営者の実際の Google AdMob 広告ユニット（リワード1つ、インタースティシャル1つ）を使用するため、Google とその広告技術パートナーの実際の広告が表示されます。広告はすべて全画面です。バナー広告はありません。報酬は報酬を獲得して広告を閉じた後にのみ付与されます。リワード広告は、利用者が視聴を選んだ場合にのみ表示されます。

  • ゲームオーバー後のコンティニュー（結果画面、1プレイにつき1回）
  • 死亡時またはクリア時の結果画面でのフルーツ2倍（1プレイにつき1回、そのプレイで獲得したフルーツが0より多い場合のみ）
  • ショップでのデイリーフルーツ +100（端末のローカル日付で1日1回）
  • ショップのシールドカードからのその日限りのシールド +1（1日1回）。そのシールドは当日の SHIFT と CLAIM のプレイに適用されます
  • ショップのマグネットカードからの1プレイ分のマグネット（1日最大3回、待機できるのは1プレイ分まで）。マグネットを所持している間はカードが表示されません
  • ショップのスキン画面からの24時間のスキン体験。同時に有効な体験は1つのみです。セレスティアルのスキンは広告2回が必要です

インタースティシャル広告は、新しいプレイを開始するとき（START または RETRY）に表示されることがあります。ゲームオーバーが3回終わると表示予定になります。リワード広告の視聴完了から60秒以内には表示されず、事前に読み込まれていない場合はスキップされます。

Google の Mobile Ads 自動初期化と Play ゲームズの自動初期化は使用していません。起動時、アプリは読み取り専用の UMP 同意情報リクエストを行います。このリクエストはフォームを表示せず、Ads SDK も起動しません。設定画面に表示する同意状態を取得するだけです。UMP が同意が必要と報告した場合、同意フォームは新しいプレイの最初の START 時または最初のリワード広告の視聴時に読み込まれ、表示されます。その後アプリは、UMP が広告リクエストを許可しているかを確認します。許可されている場合に限り、別プロセスで広告コンテンツのレーティング上限 T を設定して Mobile Ads を初期化し、広告を読み込みます。アプリはパーソナライズされていない広告のみに限定せず、TFCD、TFUA、年齢制限付きの取り扱いも設定しません。アプリは年齢や地域によって広告をオフにしません。Google の UMP が広告をリクエストできると判断した場合（同意が不要な地域を含む）、すべての利用者に同じ方法で広告をリクエストします。EEA・英国などで同意を拒否した場合でも広告はリクエストされることがあり、その場合 Google は選択内容に応じてパーソナライズされていない広告または制限付きの広告を配信します。同意の確認を完了できなかった場合（ネットワークエラーなど）や広告を読み込めなかった場合は、広告なしでゲームが続行され、報酬は広告を最後まで視聴して閉じた場合にのみ付与されます。アプリが独自の地域ルールを追加することはありません。EEA・英国向けのメッセージや米国の州向けのメッセージを含め、メッセージが必要かどうかは Google UMP が判断します。

5. 広告とプライバシーの選択

アプリ内での年齢確認はなく、年齢を設定する操作もありません。広告コンテンツのレーティング上限は T です。子ども向け（TFCD）、同意年齢未満（TFUA）、年齢制限付きの取り扱いのフラグは設定しません。アプリはパーソナライズされていない広告のみに限定しません。これらの説明は、Google Mobile Ads SDK が情報を処理しないという意味ではありません。

同意フォームは起動時には表示されません。Google UMP が選択を必要とする場合、最初の START 時または最初のリワード広告の視聴時に表示されます。アプリは年齢や地域によって広告をオフにしません。Google の UMP が広告をリクエストできると判断した場合（同意が不要な地域を含む）、すべての利用者に同じ方法で広告をリクエストします。EEA・英国などで同意を拒否した場合でも広告はリクエストされることがあり、その場合 Google は選択内容に応じてパーソナライズされていない広告または制限付きの広告を配信します。同意の確認を完了できなかった場合（ネットワークエラーなど）や広告を読み込めなかった場合は、広告なしでゲームが続行され、報酬は広告を最後まで視聴して閉じた場合にのみ付与されます。

UMP がプライバシー オプションが必要と報告した場合、設定の「Privacy options」（プライバシー オプション）からそのフォームを開き、選択を変更または撤回できます。設定にある韓国語版・英語版のプライバシーポリシーへのリンクは外部ブラウザで開き、広告の同意の選択には左右されません。同意状態を確認できなかった場合は、設定の「Retry with current choice」（現在の選択で再試行）で再確認できます。選択を変更しただけでは、Google がすでに保有している情報は削除されません。

14歳未満の利用者の個人情報が必要なお問い合わせは、保護者を通じてご連絡ください。お子さまの氏名、正確な生年月日、写真、位置などの不要な情報は送らないでください。不要な子どもの情報を把握した場合は、必要最小限の対応と速やかな最小化・削除を優先します。

8. 保存期間と削除

端末内のゲームデータは、ゲームの提供と進行状況・設定の保持のために保存されます。Android でアプリのデータを消去したりアンインストールしたりすると削除されることがあり、進行状況、通貨、設定が失われます。メニューやバックアップの動作は端末によって異なります。OS のバックアップや移行によるコピー、外部サービスのデータが同時に削除されることは保証されません。

Google の SDK とサービスの保存期間は、情報の種類、目的、アカウントとサービスの設定、セキュリティ、法的義務によって異なります。一部の情報は削除リクエストやアカウントの管理機能で管理され、一部は所定の期間後に期限切れまたは匿名化され、一部は限定的な理由でより長く保存されます。本ポリシーは、すべての SDK データについて1つの固定の保存期間を定めるものではありません。

運営者が保有するサポートのメッセージと添付ファイルは、お問い合わせの完了後90日以内に削除します。対応中のお問い合わせや法令で保存が必要な記録は個別に判断し、不要または機微な情報はより早く最小化します。メールボックス提供者や GitHub による独自のセキュリティ、バックアップ、その他の処理が同じ期限で消去されることは保証されません。

12. 任意の Google Play ゲームズ ランキング

ランキングは任意の機能で、Google Play Games サービスを使用します。Play ゲームズ SDK は起動時には初期化されません。ランキング画面を開いたとき、または SHIFT か CLAIM のプレイが終わったときに初期化されます。アプリはまず Play ゲームズで認証済みかどうかを確認します。Play ゲームズの自動ログインの設定によっては、この確認だけでタップなしに接続されることがあります。操作を伴うログインは、ランキング画面のログインボタンからのみ行われます。ログインしなくても通常のプレイは利用できます。ランキングは、ネットワークの接続状況や Google のサービスの提供状況によって制限されることがあります。

SHIFT または CLAIM のプレイが終了し、そのプレイが練習やチュートリアルではなく、プレイヤーがすでにログインしている場合、アプリはそのプレイのモード、難易度、スコアを6つのリーダーボードのいずれかに送信します。リーダーボードは SHIFT と CLAIM のそれぞれに easy、normal、crazy があります。CLASSIC のプレイは送信しません。フルーツやショップでの購入内容も送信しません。送信待ちのキューはメモリ上にのみ保持します。アプリの Play ゲームズのログにはモード、難易度、結果コードのみが記録され、そのログを開発者のサーバーにアップロードすることはありません。

ログインしたプレイヤーについて、アプリはプレイヤー ID、表示名、アイコンの URI を受け取ります。公開リーダーボードからは、他のプレイヤーのプレイヤー ID、表示名、順位、スコアを受け取ります。ランキング画面には名前が表示され、アイコンの URL は表示されません。読み取るのは公開コレクションのみです。この機能はメールアドレスを要求しません。開発者はランキングサーバーを運営していません。

ログイン、スコアの送信、取得の過程で、Google は独自のポリシーに基づいて情報を処理することがあります。Google は世界各地のサーバーで情報を処理することがあり、Play ゲームズのアカウント・ランキング情報も大韓民国外で処理されることがあります。処理、保存、国外での処理、削除には Google のポリシーとアカウントの手続きも適用されます。アプリのアンインストールや端末内データの消去だけで、Google が保有するリーダーボードの記録が削除されることは保証されません。ログインに使うアカウントと自動ログインの設定は、Play ゲームズのアカウントとプロフィールの設定で管理します。
